# Upstream contributions

This fork retains the MIT license and copyright notice in [LICENSE](LICENSE).

The structured semantic-review payload and substantial-prose rule adapt concepts
and code from [Sam Havens's PR 125](https://github.com/eric-tramel/slop-guard/pull/125),
revision `fcfa7072b409bcf498b7d43e6ef71d0656db93c4`.
The fork supplies its own audience profiles, phrase inventory, and review criteria.

The report-only `sg-hook` adapter, hook fixtures, and their tests derive from
[Eric Tramel's PR 123](https://github.com/eric-tramel/slop-guard/pull/123), revision
`b38a416ea60c0ac86936dc3cbb5493f66cf778f7`. This fork adds explicit preset selection.
